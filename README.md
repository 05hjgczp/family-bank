# 家庭银行 (Family Bank) 🏦

儿童财商教育记账 PWA，通过配资机制引导理性消费，通过利息机制培养储蓄习惯。

## ✨ 功能特性

- **劳动记账** — 记录孩子完成任务所得报酬
- **配资消费** — 按消费类型自动计算配资扣款（个人承担 + 银行补贴）
- **存款生息** — 每日复利计算，App启动自动补算
- **流水透明** — 三列金额展示：消费/扣款/配资
- **规则可配** — 存入来源与消费类型支持新增/修改
- **密码保护** — 关键操作需密码确认
- **离线可用** — 纯本地存储，无需联网
- **可安装** — 支持添加到手机主屏幕

## 📱 预置配资规则

| 消费类型 | 个人承担 | 银行配资 | 典型场景 |
|---------|---------|---------|---------|
| 自己喜欢·父母不同意 | 90% | 10% | 买零食、玩具 |
| 有利提升·父母不同意 | 50% | 50% | 学画画、兴趣班 |
| 双方认可·有价值 | 10% | 90% | 买书、辅导班 |

## 🚀 部署

### GitHub Pages

1. 上传整个 `family-bank/` 目录到仓库
2. 在仓库 Settings → Pages 中选择分支和目录
3. 访问 `https://<username>.github.io/<repo>/`

### 本地运行

直接用浏览器打开 `index.html` 即可（Service Worker 需 HTTP 服务器）。

```bash
# 或用简单服务器
npx serve .
# 或
python3 -m http.server 8000
```

## 🔒 安全说明

- 所有数据存储在浏览器 IndexedDB 中，不上传任何服务器
- 默认管理密码 `admin`，建议首次使用后修改
- 密码丢失无法找回，可通过导出/导入重置

## 📊 数据备份

- **导出**：我的 → 导出数据，生成 JSON 备份文件
- **导入**：我的 → 导入数据，选择备份文件恢复

## 技术栈

- 纯前端 PWA（HTML + CSS + JavaScript）
- IndexedDB 本地存储
- Service Worker 离线缓存
- 无任何外部依赖
