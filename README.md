# 🏦 家庭银行 PWA

> 一款帮助孩子建立正确理财观念的亲子财务管理应用。完全离线可用，数据存储在本地设备。

## 📱 功能概览

### 首页
- **余额卡片**：实时显示可用余额、累计存入、累计支出、累计利息
- **快捷操作**：一键记录存入、记录消费、利率设置
- **今日概览**：今日存入/支出金额统计
- **最近流水**：最近10条交易记录快速查看

### 记账
- 💰 **存入模式**：选择存入来源（任务报酬/零花钱/压岁钱/其他）、输入金额、添加备注
- 🛒 **消费模式**：选择消费类型、输入消费总额，实时预览个人承担金额与银行配资比例
- **配资规则**：消费时银行自动按规则配资补贴，减轻孩子负担

### 流水明细
- 支持按「全部/存入/支出/利息」分类筛选
- 支持按「今天/本周/本月/全部」时间筛选
- 按日期分组显示，底部汇总统计

### 规则管理
- **利率卡片**：显示年利率、日利率、累计利息、余额
- **存入来源管理**：新增/编辑存入来源，修改后历史记录自动同步
- **消费配资规则**：4条预置规则 + 自定义规则，个人承担比例可滑块调整

### 我的
- 修改子女账户名称（同步更新全应用显示）
- 修改银行名称
- 利率设置
- 配资规则管理入口

### 利息计算
- 每日复利计息，打开App自动计算从上次计息到今天的利息
- 每日利息 = 当日余额 × 日利率（年利率 ÷ 365）
- 利息自动加入余额，次日基于新余额继续计息

## 🔧 技术特性

| 特性 | 说明 |
|------|------|
| PWA离线应用 | Service Worker缓存所有资源，无网络也可使用 |
| 本地数据存储 | 所有数据保存在localStorage，永不丢失 |
| 独立显示模式 | 添加到主屏幕后像原生App一样全屏运行 |
| iPhone适配 | 针对Safari和刘海屏优化，安全区域适配 |
| 无外部依赖 | 100%纯代码，无CDN，无网络图片 |
| 数据快照机制 | 存入来源/消费规则修改后，历史流水自动同步 |

## 📲 安装方法（iPhone）

### 方法一：Safari 分享菜单
1. 用 iPhone Safari 打开应用网页
2. 点击底部 **分享按钮**（矩形箭头 ↑）
3. 向下滑动，找到 **「添加到主屏幕」**
4. 点击后右上角「添加」即可

### 方法二：直接添加
1. Safari 中长按地址栏
2. 选择 **「添加到主屏幕」**

### 安装后效果
- 📱 应用图标显示在主屏幕
- 🖥 点击打开无浏览器地址栏，全屏独立运行
- ✈️ 支持飞行模式下离线使用
- 🔄 有网络时会自动更新版本

## 💾 数据说明

所有数据均存储在浏览器localStorage中：
- `hb_child_name` - 子女名称
- `hb_sources` - 存入来源列表
- `hb_rules` - 消费配资规则
- `hb_transactions` - 交易流水记录
- `hb_rate` - 年利率
- `hb_balance` - 当前余额
- `hb_total_deposit` - 累计存入
- `hb_total_expense` - 累计支出
- `hb_total_interest` - 累计利息

> ⚠️ **注意**：清除浏览器数据会导致应用数据丢失，建议定期备份。如需迁移，请导出数据后重新导入。
